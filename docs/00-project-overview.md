# 交通信号控制平台项目总体规划

## 1. 项目基本信息

- 项目名称：交通信号控制平台
- 英文名称：Traffic Signal Control Platform
- 项目目录：D:\Projects\traffic-signal-control-platform
- 仿真地点：天津市河东区新开路与华龙道交叉口
- 开发环境：Windows、VS Code、Docker、SUMO
- 后端：Python、FastAPI、TraCI
- 前端：React、TypeScript、Vite
- 数据库：PostgreSQL
- 版本管理：Git

## 2. 项目总体目标

建立一个基于 SUMO 的单路口交通信号控制仿真平台。

实现道路、车道、机动车、交通信号灯、信号机和倒计时的仿真展示。

支持通过浏览器管理信号相位、调整信号配时，并实时观察信号灯变化和机动车通行情况。

## 3. 核心功能

1. 单个十字路口道路及车道仿真。
2. 机动车生成、行驶、停车及转向。
3. 交通信号灯红、黄、绿状态控制。
4. 信号机相位及配时管理。
5. 红灯最后10秒倒计时。
6. 绿灯最后8秒过渡及3秒黄灯。
7. 浏览器实时展示路口交通状态。
8. REST API及WebSocket实时通信。
9. 仿真运行管理。
10. 控制记录和运行数据持久化。

## 4. 技术架构

- 前端：React + TypeScript + Vite

- 仿真：SUMO + TraCI
- 实时通信：WebSocket
- 数据库：PostgreSQL
- 部署：Docker Compose
- 版本管理：Git

## 6. 工程开发规范

### 6.1 模块注释

每个业务模块顶部使用5行注释，说明：

- 模块功能
- 输入
- 输出
- 依赖
- 调用方

### 6.2 类型标注

Python函数使用类型标注。

FastAPI接口使用Pydantic请求及响应模型。

TypeScript接口定义明确的数据类型。

### 6.3 Git提交规范

采用以下提交前缀：

- feat：新增功能
- fix：问题修复
- docs：文档更新
- refactor：代码重构
- test：测试
- chore：工程配置

### 6.4 文档管理

所有正式项目文档统一保存在docs目录。

README必须保持启动、部署命令最新且可复现。

每个工作日更新开发日志。
